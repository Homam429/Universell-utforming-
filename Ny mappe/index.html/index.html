Universell utforming og WCAG

På denne nettsiden forklarer jeg hva universell utforming er, hvorfor det er viktig og hva Uutilsynet arbeider med.

1. Hva menes med universell utforming, og hva står WCAG for?

Universell utforming betyr at produkter, tjenester og digitale løsninger skal kunne brukes av så mange mennesker som mulig. Det gjelder også personer som har ulike funksjonsnedsettelser.

WCAG står for Web Content Accessibility Guidelines. Dette er retningslinjer for hvordan vi kan lage nettsider som er mer tilgjengelige. Det kan for eksempel handle om god kontrast, tydelige overskrifter, alt-tekst på bilder og at nettsiden kan brukes med tastatur.

2. Hva kan skje hvis vi ikke følger universell utforming?

Hvis vi ikke tenker på universell utforming, kan noen mennesker få problemer med å bruke nettsiden. En person med nedsatt syn kan for eksempel ha problemer med å lese tekst dersom kontrasten mellom teksten og bakgrunnen er for dårlig.

En person som ikke kan bruke mus, kan også bli utestengt dersom nettsiden ikke fungerer med tastatur. Konsekvensen kan derfor være at noen ikke får tilgang til den samme informasjonen eller tjenesten som andre.

3. Hvem er Uutilsynet, og hva er deres primæroppgaver?

Uutilsynet er Tilsynet for universell utforming av IKT. De følger opp reglene om universell utforming av digitale løsninger i Norge.

En viktig oppgave er å kontrollere om virksomheter følger kravene til universell utforming. De gir også informasjon og veiledning om reglene og arbeider med å få oversikt over hvordan det står til med universell utforming av IKT.
