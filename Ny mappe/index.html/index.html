Universell utforming og WCAG

I denne nettsiden jeg skal svare på flere spørsmål om hva universell utforming er & hvorfor er det viktig og hva Uutilsynet arbeider med.

1: Hva menes med universell utforming og hva står WCAG for?

Universell utforming betyr at ting skal lages sånn at flest mulig kan bruke dem. Det kan for eksempel være nettsider, apper eller andre tjenester. Man må også tenke på personer som har funksjonsnedsettelser, slik at de også kan bruke løsningene.

WCAG står for Web Content Accessibility Guidelines. Det er noen regler som gjør nettsider lettere å bruke for alle.

2. Hva kan skje hvis vi ikke følger universell utforming?

Uten universell utforming kan noen få problemer med å bruke nettsiden. For eksempel kan dårlig kontrast gjøre teksten vanskelig å lese.

Om nettsiden ikke fungerer med tastatur. kan noen få problemer med å bruke den og finne informasjon.

3. Hvem er Uutilsynet, og hva er deres primæroppgaver?

Uutilsynet passer på at digitale løsninger i Norge følger reglene for universell utforming.

De sjekker om bedrifter følger reglene, og gir hjelp og informasjon om universell utforming.
